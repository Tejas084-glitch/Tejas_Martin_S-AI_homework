#Approach 
1. I run the command pwd to check the current directory location
2. Created a folder named project-files using mkdir
3. Ran the ls command to check if folder is Created
4. Located inside project-files using cd
5. Made three new files using touch 
6. copied report.docx and renamed it report_backup.docx
7. made a new folder named old 
moved draft.docx into old 
renamed summary.docx to final_summary using mv command
copied final_summary.docx into old
removed report_backup.docx using rm command
