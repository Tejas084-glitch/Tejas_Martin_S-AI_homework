#Solution
cd breach_response
chmod +w evidence
cp evidence/log_dump.txt .
mv evidence secure
chmod 555 secure/evidence
chmod +w reports/incident_summary.txt
echo "Breach confirmed" >> reports/incident_summary.txt
echo "Forensics Complete" > secure/forensics_report.txt
chmod 600 secure/forensics_report.txt
echo "Escalated to security team" >> reports/incident_summary.txt
chmod 444 reports/incident_summary.txt

#Approach
1. First I navigated into the breach_response directory using cd
2. Then Gave the write permission to evidence
3. Copied evidence/log_dump.txt into breach_response
4. Moved evidence into secure using mv
5. Changed back the permissions for secure/evidence to 555 
6. Gave reports/incident_summary.txt write permission to write content in it
7. After creating and writing content into secure/forensics_report, I set its to 600
8. After appending more content in reports/incident_summary.txt, Changed back its permissions to 444
